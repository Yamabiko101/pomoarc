# Pomolife Review Contracts

The project uses conceptual specialist reviews during development:

- Architect: module boundaries and coupling.
- Timer engine: domain correctness and edge cases.
- UX/TUI: responsive terminal behavior.
- QA: build, test, clippy and install checks.
- Release manager: README and macOS installation.

Final release checks should cover dependencies, reproducibility, packaging,
resource use and terminal accessibility.
